# Отчёт о наполнении каталога v2 (ветка `catalog-real`)

Итоговый отчёт по разделу 13.1, этап 7 ТЗ ([docs/ТЗ_БД_v2_промт_для_нейросети.md](ТЗ_БД_v2_промт_для_нейросети.md)).
Дата: 22.11.2026. Исполнитель: Claude Opus 5.5.

## Доступ к источникам и дата знаний

- Доступ к интернету: **да**. Использованы API Wikipedia и Wikimedia Commons, официальные страницы Apple, Google и Samsung,
  публичные веб-превью Telegram-каналов проекта и поисковые выдачи.
- Собственные сведения нейросети — **до июня 2026 года**. Модели, вышедшие позже, по памяти не заполнялись (правило 16).
  Для них взяты поля старой базы (`project_seed`), а характеристики и камеры — со страниц Wikipedia и производителей.
- GSMArena не использовалась как источник для выгрузки: в её `license.xml` прямо запрещено использовать материалы
  для ИИ (`ai-inference`, `ai-train`). Kimovil отвечает 403, DeviceSpecifications закрыта проверкой браузера.
  Обходить такие защиты запрещено правилом 15.

## Как помечены данные

| Пометка | Что значит в этом каталоге |
|---|---|
| `estimated` + `ai_knowledge` | Характеристики, камеры и оценки обработки из сведений нейросети. Со страницей не сверены |
| `verified` + `wikipedia:<статья>` | Батарея, вес, экран и частота взяты из карточки статьи Wikipedia (`tools/verify_wikipedia.py`) |
| `verified` + `manufacturer:<страница>` | Страница производителя загружена и прочитана: iPhone 17e, iPhone 18 Pro / Pro Max, iPhone Duo |
| `verified` + `telegram_*:t.me/<канал>/<пост>` | Цена из публичного канала с датой и ссылкой на пост: медиана за 30 (иначе 60) дней |
| `estimated` + `price_model` | Цена остальных конфигураций пересчитана от базовой по MSRP или по шагу памяти |
| `estimated` + `project_seed` | Поля и цены старой базы проекта (`data/phones_seed.csv`) |
| `unknown` | Значение не найдено: цена в РФ, оценка обработки у моделей после июня 2026 |

«Приколы» с пометкой `verified` подтверждены официальной страницей (`tools/check_quirk_evidence.py`):

- 7 лет обновлений у Pixel 8 и новее — страница поддержки Google;
- 7 лет обновлений у Galaxy Z Fold6 и Flip6 — страница поддержки Samsung;
- ограничения Apple Intelligence в РФ: русского языка нет в списке поддерживаемых — страница поддержки Apple;
- отсутствие сервисов Google у Huawei — статья о Huawei Mobile Services.

Остальные «приколы» — оценка нейросети по обзорам, без ссылок. Поэтому `quirks_checked` везде `false`
(правило H5). Ставить `true` без проверки обязательных источников раздела 10 было бы подлогом.

## Что изменено в коде и схеме

- `tools/import_catalog_data.py` — компактные таблицы `tools/catalog_data/*.txt` → файлы моделей. Slug, имена и
  `in_ml` 285 моделей рандом-версии не менялись (правило 11).
- `tools/build_catalog.py`:
  - если сенсор не назван, итог модуля равен оценке обработки;
  - модель без фото — предупреждение (на сайте «Место для фото»), критерий 100% остаётся в `--final`.
- `tools/scrape_telegram.py` — повторы при таймаутах; название модели берётся и из строки над ценой.
- Rust: версия 0.3.0 «каталог v2 — настоящие данные», плашка о происхождении данных, тесты под настоящий каталог.
- ТЗ — версия 1.2: раздел «Что нового в 1.2».

## Переобучение нейросети

Обучающая база Python теперь выгружается из каталога (`tools/catalog_to_seed.py`). В подбор входят 429 моделей
с `in_ml: true` и ценой базовой конфигурации; раньше было 282. После переобучения KMeans выбрал 12 групп.
Golden-тест подтверждает, что Rust по-прежнему совпадает с Python: 60 анкет из 60. У трёх моделей
(iPhone 18 Pro, Pixel 11 Pro, Pixel 11 Pro XL) AnTuTu неизвестен — очистка данных подставила среднее.
Порядок переобучения — в корневом README, раздел «Переобучение нейросети на каталоге».
